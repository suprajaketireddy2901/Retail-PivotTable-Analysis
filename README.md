# Retail Sales Analysis Using Excel

## Project Overview

This project analyzes retail sales data using **Microsoft Excel PivotTables and PivotCharts**.

The objective is to transform transaction-level data into meaningful summaries and visual insights that can support business and sales analysis.

## Business Objective

The analysis focuses on:

* Understanding overall sales performance
* Analyzing sales by product
* Comparing sales across locations
* Identifying high-performing products
* Analyzing customer and transaction patterns
* Understanding sales trends over different time periods

## Tools Used

* Microsoft Excel
* PivotTables
* PivotCharts
* Data Analysis
* Business Analysis

## Analysis Performed

The workbook contains PivotTable-based analysis including:

* Total sales by product
* Sales by location
* Customer-level sales analysis
* Product transaction counts
* Average sales/value by product
* Monthly sales analysis
* Quarterly sales analysis
* Yearly sales analysis
* Time-period comparisons

## Visual Analysis

PivotCharts are used to present sales patterns and comparisons in a visual format, making it easier to identify trends and differences across products, locations, and time periods.

## Business Insights

The analysis can help identify:

* High-performing products
* High-performing locations
* Sales trends over time
* Customer and transaction patterns
* Areas requiring further business analysis

**Microsoft Excel | PivotTables | PivotCharts | Retail Sales Analysis | Data Analysis | Business Analysis | Data Visualization**
